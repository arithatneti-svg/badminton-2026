คอลัมน์หลัก
PTS = Match Points (ชนะ +3, เสมอ +1, แพ้ +0)
±PD = Point Differential (แต้มได้รวม − แต้มเสียรวม)
GW/GL = Game Wins/Losses (ระดับเกม)
WR% = Game Win Rate = GW ÷ (GW+GL) × 100
M = จำนวน Match · D = Match Draw
Prediction & BaseScore
Base Score = ค่าความสามารถรายบุคคล (0.5–3.0 ขยับทีละ 0.5)
Prediction = เปรียบ BS รวมทีม: diff=0→25/50/25%, diff=0.5→65/20/15%, diff=1.0→75/15/10%, diff≥1.5→85/10/5%
PRED ACC = % แมตช์ที่ทีม win% สูงกว่าชนะจริง
PERF Score & Under/Over
PERF = Performance Score ปรับตามความยากคู่แข่ง
Underrated = WR จริง > คาดจาก BS (+15% ขึ้นไป) → ควรเพิ่ม BS
Overrated = WR จริง < คาดจาก BS (−15% ลงไป) → ควรลด BS
opp adj = ปรับตาม BS เฉลี่ยของคู่แข่งที่เจอ ±8%
⚡ UPSETS = แมตช์ที่ทีม BS ต่ำกว่าพลิกชนะ

🏆 MVP Top 5 (ผู้ทำแต้มสูงสุด):
เรียงจากผู้ที่สะสมแต้มทีมได้มากที่สุด
ตัดเชือก: Points → Point Diff → Game Wins

🛡️ Toughest Player (ผู้เล่นเคี้ยวยาก):
ผู้เล่นที่พาทีมเสมอได้บ่อยที่สุด สะท้อนความสมดุลและความสม่ำเสมอ
ตัดเชือก: Draws มากสุด → |Point Diff| ใกล้ 0 มากสุด

🔥 Epic Comeback Kings (ราชาพลิกนรก):
ตามหลัง 4+ แต้มช่วงท้ายในขณะที่คู่ต่อสู้มีแต้ม 17 ขึ้นไป แล้วพลิกชนะได้
เกิดได้ 2 ครั้งต่อ Match · ได้รับเฉพาะทีมที่พลิกชนะ
ตัดเชือก: Tags → Wins → Point Diff

⚔️ The Gladiators (นักสู้หัวใจเพชร):
แต้มรวม 2 เกมของทั้งแมตช์ห่างกันไม่เกิน 5 แต้ม — เกมสูสีสุดขีด
ตัดเชือก: Tags → |Point Diff| ใกล้ 0 → Draws

🏃‍♂️ Iron Lungs (ปอดเหล็ก):
ผ่านเกมที่มีดิวซ์ยาวนานถึง 22 แต้มขึ้นไป ทดสอบความอดทนสูงสุด
ตัดเชือก: Tags → Wins → Point Diff
