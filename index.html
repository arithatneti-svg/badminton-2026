แก้ Tag ของแมตช์

กติกาการตัดสินรางวัล

  • MVP Top 5 (ผู้ทำคะแนนสูงสุด)

    เรียงจากผู้ที่สะสมคะแนนทีมได้มากที่สุด

    ตัดเชือก: Points → Point Diff → Game Wins
  • Toughest Player (ผู้เล่นเคี้ยวยาก)

    ผู้เล่นที่พาทีมเสมอได้บ่อยที่สุด สะท้อนความสมดุลและความสม่ำเสมอ

    ตัดเชือก: Draws มากสุด → |Point Diff| ใกล้ 0 มากสุด
  • Epic Comeback Kings (ราชาพลิกนรก)

    ตามหลัง 4+ คะแนนช่วงท้ายในขณะที่คู่ต่อสู้มีคะแนน 17 ขึ้นไป แล้วพลิกชนะได้ เกิดได้ 2 ครั้งต่อ Match · ได้รับเฉพาะทีมที่พลิกชนะ

    ตัดเชือก: Tags → Wins → Point Diff
  • The Gladiators (นักสู้หัวใจเพชร)

    คะแนนรวม 2 เกมของทั้งแมตช์ห่างกันไม่เกิน 5 คะแนน — เกมสูสีสุดขีด

    ตัดเชือก: Tags → |Point Diff| ใกล้ 0 → Draws
  • Iron Lungs (ปอดเหล็ก)

    ผ่านเกมที่มีดิวซ์ยาวนานถึง 22 คะแนนขึ้นไป ทดสอบความอดทนสูงสุด

    ตัดเชือก: Tags → Wins → Point Diff
รางวัล Rollercoaster และ Blowout ไม่มีในพิธีมอบรางวัล แต่ยังปรากฏใน Match History
