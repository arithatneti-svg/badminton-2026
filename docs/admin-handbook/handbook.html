Badminton Sports Day 2026

เสาร์ที่ 14 พ.ย. 2569 · สนามไดมอนด์ · เริ่มงาน 12:30 น. · 5 คอร์ต · 3 รอบ · แดง vs น้ำเงิน

เขียนสำหรับแอปเวอร์ชัน 2026.11.14.4 (ดูเลขเวอร์ชันได้ที่ท้ายหน้าเข้าระบบหรือมุมจอ TV) ถ้าเวอร์ชันบนเว็บต่ำกว่านี้ ข้อที่เขียนว่า “รุ่น .3” หรือ “รุ่น .5” อาจยังไม่เป็นจริง · เอกสารนี้ ไม่มีรหัสผ่าน ต้องถามเจ้าของระบบ

เอกสารนี้ใช้ทำอะไร

ให้ผู้จัดงานวางเอกสารนี้ในแชตกับ AI (เช่น Claude) แล้วถามเมื่อเกิดปัญหาหน้างานตอนเจ้าของระบบไม่อยู่ AI ต้องตอบโดยอ้างจากเอกสารนี้ และแนะนำ วิธีในแอปก่อนเสมอ วิธีแก้ที่หลังบ้าน (ฐานข้อมูล) อยู่ในภาคผนวก ก. ใช้เมื่อไม่มีทางอื่นเท่านั้น

ข้อความเริ่มต้นที่แนะนำให้พิมพ์ก่อนถาม: “คุณคือผู้ช่วยแอดมินของงานกีฬาสีแบดมินตัน ใช้เอกสารนี้เป็นความรู้หลัก ตอบสั้น ๆ เป็นขั้นตอนทีละปุ่ม ถ้าไม่แน่ใจให้บอกว่าไม่แน่ใจ ห้ามเดา ก่อนแนะนำสิ่งที่ลบหรือเขียนทับข้อมูลต้องเตือนให้สำรองข้อมูลก่อนและถามยืนยันเสมอ”

กฎเหล็กสำหรับ AI และผู้จัด (อ่านก่อนทำอะไร)
  1. วิธีในแอปก่อน ทุกปัญหาที่ทำผ่านปุ่มในแอปได้ ให้ใช้ปุ่ม ไม่แก้ฐานข้อมูลตรง
  2. สำรองก่อนลบหรือแก้ใหญ่: หน้า Admin → Backup ตอนนี้ (ระบบสำรองอัตโนมัติหลังจบทุกแมตช์และก่อน Reset/กู้คืนอยู่แล้ว เก็บ 30 ชุดล่าสุด)
  3. อย่าขึ้นเวอร์ชันใหม่ (push/deploy) ระหว่างงาน ทุกเครื่องจะเห็นแถบ “มีเวอร์ชันใหม่” และจอ TV รีโหลด
  4. ห้ามกดปุ่ม “สรุปผลการแข่งขัน (Ceremony)” เพื่อลอง ปุ่มนี้ส่งภาพถ้วยรางวัลขึ้นจอ TV ทุกเครื่องทันที กดตอนประกาศผลจริงเท่านั้น
  5. ห้ามพิมพ์รหัสผ่านแอดมินลงในแชต AI และ AI ต้องไม่ขอรหัสผ่าน
  6. เรื่องกติกา (ใครชนะ ตัวแทน ตัดสินเสมอ) ต้องให้ ผู้จัดทั้งสองสี ตกลงกัน AI แค่ช่วยทำในระบบตามที่ตกลง
  7. ฐานข้อมูลเปิดให้เขียนได้ ใครมีลิงก์ก็แก้ได้ ถ้าข้อมูลเปลี่ยนเองโดยไม่มีใครทำ ให้สงสัยว่ามีคนลองเล่น และกู้จาก Backup

2. เช็กลิสต์วันงาน

ก่อนเปิดงาน (ก่อน 12:30)

  1. เปิด /?view=tv บนคอมที่ต่อจอ เช็กว่าแถบเชื่อมต่อไม่เป็นสีแดง เปิดเต็มจอ
  2. เปิดหน้า Admin (Admin หรือ Super Admin) กด Backup ตอนนี้ 1 ครั้งเป็นจุดตั้งต้น
  3. ตรวจว่าคิวและกล่องรอว่างจากแมตช์ทดสอบ (หน้า Admin “แมตช์ทั้งหมด” ต้องว่าง) ถ้ามีแมตช์ค้างจากการทดลอง ให้ลบ (ดูหัวข้อ 3.F)
  4. ตรวจรายชื่อผู้เล่นครบ ทีมละ 20 คน (ผู้เล่นที่ไม่มีทีมจะไม่ถูกเลือกในระบบสร้างแมตช์)
  5. กรรมการ 5 คน เปิด /umpire เลือกชื่อตัวเองให้เสร็จก่อนเริ่ม เปิดแอปค้างและต่อที่ชาร์จ
  6. หน้า Admin → แผง “กรรมการ — แนะนำ & มอบหมาย” ติ๊กรายชื่อคนที่ว่างมาเป็นกรรมการวันนี้ (ดูหัวข้อ 3.R)
  7. สำรองเน็ต: เปิดฮอตสปอตมือถือเตรียมไว้ (ถ้า Wi-Fi สนามล่ม)

ระหว่างงาน

  1. รอบ 1 และ 3: ผู้จัดตกลงคู่กันเอง แอดมินคีย์ที่ สร้างแมตช์ → ลงกล่องรอ → ต่อคิว (ดู 3.A)
  2. รอบ 2: สุ่มที่ /round2 หลังจบรอบ 1 → ยืนยัน → คู่ลงกล่องรอ → ต่อคิว
  3. กรรมการรับแมตช์จากคิวและเลือกคอร์ต แอดมินดูหน้า “แมตช์ทั้งหมด” ว่าคอร์ตไหนว่าง
  4. กด Backup ตอนนี้ ทุกครึ่งชั่วโมงเพิ่มได้ (ไม่บังคับ ระบบสำรองหลังจบทุกแมตช์อยู่แล้ว)

ปิดงาน

  1. ตรวจคะแนนรวมสี (หน้า Scoreboard) ถ้าเสมอ ใช้ลำดับตัดสินในหัวข้อ 3.N
  2. กด Backup ตอนนี้ แล้ว Admin → สรุปผลการแข่งขัน (Ceremony) เพื่อโชว์ผลบนจอ TV (ครั้งเดียว ตอนประกาศ)
  3. หลังงาน: ส่งออก PDF/CSV ผู้เล่น (หน้าผู้เล่น/Reports) เก็บไว้

3. คู่มือแก้ปัญหาตามสถานการณ์

A. คีย์คู่แข่ง / จัดคิว (รอบ 1, 3, และเพิ่มคู่เอง)

  1. Admin → ฝั่งซ้ายคือกระดานสร้างแมตช์ เลือกทีมแดง 2 คน ทีมน้ำเงิน 2 คน (ตัวกรอง G1/G2/G3 และช่องค้นหา) หรือกด สุ่มจับคู่ แล้วตรวจก่อน
  2. กด สร้างแมตช์ → แมตช์ไปอยู่ กล่องรอ (ผู้ชมและกรรมการ ยังไม่เห็น) ได้รหัส M01, M02… ต่อเนื่อง
  3. จัดลำดับในกล่องรอโดยลากที่จุด ⠿ แล้วกด ต่อคิว ▶ (หรือลากไปวางในช่อง “คิวจริง”) → แมตช์ขึ้นคิวที่กรรมการเห็นและรับได้
  4. ผู้เล่นคนเดียวใส่หลายแมตช์ได้ ระบบไม่ห้าม (ตัวนับ “เล่นแล้ว N” อยู่ในกระดานให้เห็น)

ลบ: การ์ดในกล่องรอกด ✕ · แมตช์ในคิวใช้ปุ่ม ลบ ที่หน้า “แมตช์ทั้งหมด” (มีหน้าต่างยืนยัน)

B. เปลี่ยนตัวผู้เล่น “ก่อนแข่ง” (ยังไม่มีกรรมการรับ)

  • ระบบ ไม่มีปุ่มแก้ชื่อในแมตช์ที่สร้างแล้ว วิธีทำ: ลบแมตช์เดิม (กล่องรอ ✕ หรือปุ่ม ลบ) แล้วสร้างใหม่ด้วยคนที่ถูกต้อง แล้ว ต่อคิว ใหม่ รหัสแมตช์ใหม่จะเป็นเลขถัดไป ไม่ย้อนเลขเดิม
  • ถ้าแมตช์ถูกกรรมการรับแล้ว: กด ปล่อยแมตช์ ก่อน (กรรมการหลุดจากแมตช์ คะแนนที่นับไว้หายถ้ามี) แล้วทำตามข้อบน

C. ตัวแทนระหว่างแมตช์ที่กำลังแข่ง (กติกา: ตัวแทนลงเกมย่อยที่ 2 ได้ทันที)

ระบบยังไม่รองรับการเปลี่ยนคนกลางแมตช์ แมตช์หนึ่งมีผู้เล่น 4 คนตายตัว ให้ผู้จัดตกลงวิธีบันทึกก่อน แนะนำทางเลือก:

  1. บันทึกเป็นแมตช์เดียว กรรมการคุมต่อจนจบ ส่งผลตามปกติ แล้ว Super Admin กดไอคอนดินสอ “แก้ผล” ที่แมตช์นั้นในแท็บ “จบแล้ว” แล้วเปลี่ยนชื่อผู้เล่นเป็นคนที่เล่นเกมที่ 2 (หน้าต่างแก้ผลเปลี่ยนชื่อผู้เล่นได้) ผลคือสถิติรายบุคคลนับให้คนที่ลงท้ายแมตช์ทั้งแมตช์
  2. บันทึกเป็นชื่อคนเดิมต่อไป (ง่ายสุด) ตกลงกันว่าสถิติรายบุคคลไม่ซีเรียส สิ่งสำคัญคือคะแนนสี

คะแนนสีไม่ได้รับผลจากการเปลี่ยนชื่อ ผลต่อสถิติรายบุคคล/อันดับเท่านั้น

D. ผู้เล่นเจ็บ/ถอนตัวระหว่างเกม (กติกา: เจ็บเกม 1 = แพ้เกมย่อยที่ 1 นับแต้มตามจริง)

  1. กรรมการ: กด พัก → เจ็บ / ถอนตัว (ปิดเกมนี้) → เลือก “ทีมแดงถอน” หรือ “ทีมน้ำเงินถอน” → ยืนยัน ระบบเก็บแต้มตามจริงตอนหยุด แต่ให้ ฝั่งที่ไม่เจ็บชนะเกมนั้น เกม 1 ปิดแล้วเริ่มเกม 2 ต่อ (ตัวแทนเข้าเล่นเกม 2 ได้) ส่วนเกม 2 ปิดแล้วระบบเปิดหน้าส่งผลแมตช์
  2. แอดมิน (ใส่ผลเองแทน): หน้า “แมตช์ทั้งหมด” ปุ่ม ใส่ผลเอง (Super Admin เห็นปุ่ม Force Result ที่การ์ดสนาม) กรอกแต้มทั้งสองเกม แล้วเลือกที่ช่อง “ใครเจ็บ / ถอนตัว” ของเกมนั้น (แดงถอน/น้ำเงินถอน) ช่องแสดงผลด้านล่างจะเปลี่ยนตามทันที กดบันทึกผล
  3. การบันทึกจะจด ret1 (เกม 1) / ret2 (เกม 2) ไว้ในผลแมตช์ ใช้คำนวณคะแนนแมตช์และสถิติเกมชนะ/แพ้ แต้มในช่องยังใช้ในผลต่างแต้มรวม
  4. รุ่น .3: เมื่อ Super Admin แก้ผลแมตช์ที่มี ret1/ret2 ระบบจะคงเกมที่ถอนเป็นของฝั่งที่ไม่เจ็บ (รุ่นก่อน .3 การแก้ผลจะคำนวณจากแต้มอย่างเดียวและพลิกผลได้)
  5. ที่ยังไม่รองรับ: หน้า Reports/การ์ดที่ไฮไลต์ผู้ชนะเกมย่อยจากแต้มที่สูงกว่า อาจโชว์ฝั่งที่เจ็บเป็นสีเด่น แต่คะแนนแมตช์ถูกต้อง

E. กรรมการและแมตช์ที่กำลังแข่ง

อาการทำอะไร
กรรมการเลือกชื่อผิด / ลืมออกจากระบบกรรมการกดปุ่มเปลี่ยนกรรมการ (ไอคอนออกมุมบน) แล้วเลือกชื่อใหม่ แมตช์ที่รับไว้ยังเป็นของชื่อเดิม ถ้าต้องการให้คนอื่นคุมต่อ แอดมินกด ปล่อยแมตช์
กรรมการเดินหาย/มือถือดับ/แบตหมดเปิดมือถือเครื่องอื่น เข้า /umpire เลือก ชื่อเดิม กด “คุมต่อ” คะแนนอยู่ครบบนเซิร์ฟเวอร์ ถ้าไม่ได้ ให้แอดมินกด ปล่อยแมตช์ (คะแนนที่นับไว้หาย) แล้วให้คนอื่นรับใหม่ หรือกด ใส่ผลเอง เมื่อรู้ผลแล้ว
ปล่อยแมตช์ไม่ได้ (ขึ้นว่าเพิ่งมีความเคลื่อนไหว)มีการกดแต้มใน 1–2 วินาทีที่ผ่านมา ดูสถานะอีกครั้งแล้วลองใหม่ ระบบกันปล่อยทับกรรมการที่ยังคุมอยู่
คอร์ตซ้ำ / ตั้งคอร์ตผิดหน้า “แมตช์ทั้งหมด” การ์ดที่กรรมการรับแล้วมีตัวเลือกคอร์ต 1–10 เลือกใหม่ได้ (ถ้าคอร์ตมีแมตช์อยู่แล้วระบบถามยืนยัน ไม่ห้าม)
กรรมการกดแต้มผิดกดปุ่ม − (ข้างจอฝั่งนั้น) ลบทีละแต้ม ก่อนกดส่งผลเกม หลังกดส่งผลเกม 1 กรรมการแก้ไม่ได้ ต้องให้ Super Admin แก้ผลหลังจบแมตช์
กรรมการกดส่งผลแล้วไม่ไปต่อ / ขึ้นว่าส่งไม่สำเร็จตรวจสัญญาณ แล้วกด “ลองส่งอีกครั้ง” ได้ปลอดภัย (ระบบกันผลซ้ำ) ห้ามปิดหน้าจนกว่าส่งสำเร็จ ถ้าส่งไม่ได้เลยให้แอดมิน ใส่ผลเอง
กรรมการรับ 2 แมตช์พร้อมกันทำได้โดยระบบเตือน (บางคนคุม 2 คอร์ต) ไม่ใช่ข้อผิดพลาด
อยากให้กรรมการคนหนึ่งคุมแมตช์ที่ระบุแผง “กรรมการ — แนะนำ & มอบหมาย” ใน Admin (หัวข้อ 3.R) มอบหมายแล้วกรรมการจะเห็น “จองให้คุณ” ต้องแจ้งตัวต่อตัวด้วย เพราะแอปไม่เด้งเตือน
ไม่เห็นชื่อในรายการกรรมการชื่อมาจากรายชื่อผู้เล่นทั้งหมด ถ้าไม่เจอให้เพิ่มผู้เล่น (3.L) หรือใช้ตัวกรองทีม/กลุ่ม

F. ผลผิด / ต้องแก้ / ต้องลบ

ต้องการทำอย่างไรสิทธิ์
แมตช์ยังไม่จบ ส่งผลแทนใส่ผลเอง ดูตัวอย่างผลก่อนกดบันทึกAdmin
แก้ผลหรือเปลี่ยนชื่อผู้เล่นในแมตช์ที่จบแล้วแท็บ “จบแล้ว” → ไอคอนดินสอ แก้ผล (แก้แต้มสองเกม เลือกผู้เล่นใหม่ ระบบคำนวณคะแนนสีใหม่ให้อัตโนมัติ)Super Admin
ลบผลแมตช์ที่จบแล้ว (เช่น เป็นแมตช์ทดสอบ)แท็บ “จบแล้ว” → ไอคอนถังขยะ ลบ (หักคะแนนสีที่ได้จากแมตช์นั้นคืนอัตโนมัติ)Super Admin
คะแนนรวมสีไม่ตรงกับผลรวมแมตช์Scoreboard → ปรับคะแนนรวมทีม (ใช้เป็นทางสุดท้าย ปรับตรง ๆ ไม่ผ่านแมตช์) หรือตรวจด้วยสคริปต์ในภาคผนวก ก.5Super Admin
แก้ Tag (เช่น Comeback, Blowout)ไอคอนเหรียญ แก้ Tags ที่แมตช์ในแท็บ “จบแล้ว”Super Admin

G. เน็ตหลุด / ข้อมูลไม่อัปเดต

  • ทั้งสนามเน็ตล่ม: เปิดฮอตสปอตมือถือ 1 เครื่อง ให้ กรรมการ 5 เครื่องกับแอดมิน ต่อก่อน (ผู้ชมทีหลัง) แอปจะเชื่อมต่อกลับเอง กรรมการกดคะแนนต่อได้ในเครื่อง ระบบจะส่งเมื่อสัญญาณกลับ แต่ การส่งผลแมตช์ต้องออนไลน์ เครื่องจะบอกให้รอ
  • เห็นข้อมูลเก่า: ดึงรีเฟรชหน้า ถ้ายังเก่า ให้ปิดแท็บแล้วเปิดใหม่ เครื่องที่ติดตั้งเป็นแอปให้ปิดแล้วเปิดใหม่
  • เกินเพดาน 100 เครื่อง (Spark): เครื่องที่ 101 อาจเข้าไม่ได้หรือหลุด ข้อมูลไม่หาย ลดจำนวนแท็บที่เปิดทิ้ง หรือให้ผู้ชมบางส่วนดูจากจอ TV แทน ดูตัวเลขที่ Firebase console → Realtime Database → Usage
  • ขึ้นเตือน “บันทึกไม่สำเร็จ”: ลองอีกครั้ง ถ้าขึ้นซ้ำ ให้รีเฟรชแล้วทำซ้ำ ข้อมูลฝั่งเซิร์ฟเวอร์ปลอดภัย (การบันทึกที่ไม่สำเร็จจะไม่ทับข้อมูล)

H. จอ TV

  • เปิด: Admin กด เปิดจอ TV (ในหน้า QR) หรือเปิด /?view=tv เอง
  • จอค้าง/ว่าง: รีเฟรช (F5) แล้วกดเต็มจอ (F) ถ้าแถบแดงบอกสัญญาณหลุด แก้ที่เน็ตของคอมเครื่องนั้น
  • จอ TV ใช้รูปเต็มของผู้เล่น (ไม่ใช้รูปย่อ) และโชว์อีโมจิลอยจากผู้ชม ถ้าอีโมจิรกตา ให้ปิดอีโมจิ (3.I)
  • หน้า “MATCH FINISHED” โผล่เองเมื่อมีผลใหม่ ถือว่าปกติ

I. อีโมจิเชียร์

  • ผู้ชมกดได้ทุกคู่ที่กำลังแข่ง (🔥 สู้ ๆ · 👏 ปรบมือ · 😮 ว้าว · 💪 ไฟต์ · 😂 ฮา) จำกัดความถี่ที่ฝั่งผู้ใช้
  • ปิดฉุกเฉิน: Admin เลื่อนลงใต้กล่องรอ มีแผง “อีโมจิเชียร์” → ปิดอีโมจิ (ฉุกเฉิน) ปุ่มหายจากทุกเครื่องและ TV ยอดที่สะสมไว้ยังอยู่ กด เปิดอีโมจิ เพื่อกลับมา
  • ล้างยอด: ล้างยอดทั้งหมด (ลบแล้วเอากลับไม่ได้ มีหน้าต่างยืนยัน)
  • ปิดฟีเจอร์นี้ไม่กระทบคะแนนและผลแมตช์ใด ๆ

J. รูปผู้เล่น

  • รูปเต็มเก็บที่ sportsday_2026_photos/{id} รูปย่อ 160px ที่ sportsday_2026_thumbs/{id} สร้างครบทุกคนแล้ว (56 รูป) อวาตาร์เล็กใช้รูปย่อ รูปใหญ่/TV ใช้รูปเต็ม
  • เพิ่ม/เปลี่ยนรูปผู้เล่นใหม่ตอนวันงาน: ระบบสร้างรูปย่อให้อัตโนมัติตอนอัปโหลด ถ้าผู้เล่นใหม่ไม่มีรูปย่อ ระบบใช้รูปเต็มแทน (ช้าลงเล็กน้อย ไม่เสีย)
  • สร้างรูปย่อซ้ำ: Super Admin → Backup & Restore → สร้างรูปย่อให้ทุกคน (ปลอดภัย รันซ้ำได้ ไม่เขียนทับของเดิม)

K. สุ่มคู่รอบ 2 (/round2)

  1. เข้า /round2 ใส่รหัส Admin หรือ Super Admin กด สุ่มรอบ 2 (สุ่มใหม่กด Reshuffle ได้ไม่จำกัด)
  2. กฎของการสุ่ม: เพื่อนร่วมคู่ห่างระดับไม่เกิน 3, ทุกคู่ต่อกรห่างไม่เกิน 3, ผลรวมระดับสองฝั่งเท่ากัน, 1.1 ไม่จับกับ 1.1, พยายามไม่จับคู่คนกลุ่มย่อยเดียวกัน ทีมต้องมีจำนวนเท่ากันและเป็นเลขคู่ (ระดับ 1.1=7 ถึง 3.2=1) ถ้าขึ้นว่าจับไม่ได้ ให้ตรวจรายชื่อว่าทุกคนมีทีมและกลุ่มย่อย
  3. ยืนยัน → คู่ทั้งหมดไปอยู่ กล่องรอ (เรียงจากแมตช์เข้มข้นที่สุด) และเก็บบันทึกที่ draw_2026/round2 แล้วแอดมิน ต่อคิว ในหน้า Admin
  4. กด ยืนยันแล้วเปลี่ยนใจ: ยกเลิกที่ส่งไป เอาเฉพาะคู่ที่ ยังอยู่ในกล่องรอ ออก ส่วนคู่ที่ต่อคิวไปแล้วต้องไปลบในหน้า “แมตช์ทั้งหมด” แล้ว ลบบันทึกรอบ 2 ด้วย (ภาคผนวก ก.4) ไม่งั้นหน้านี้จะบอกว่าเคยยืนยันแล้ว
  5. ทดลองโดยไม่แตะข้อมูลจริง: /round2?test=1

L. จัดการผู้เล่น

  • Admin → ส่วนจัดการผู้เล่น: เพิ่ม ผู้เล่น (ชื่อ ทีม กลุ่ม), แก้ไข (ไอคอนดินสอ), ลบ, นำเข้า CSV/JSON, ส่งออก CSV/JSON
  • ผู้เล่นที่ ไม่มีทีม/กลุ่มย่อย (ตอนนี้มี 22 คนจาก 62) จะไม่ถูกใช้ในการสุ่มรอบ 2 และเลือกในกระดานสร้างแมตช์ไม่ได้ ตรวจว่าตั้งใจ
  • เปลี่ยนทีมผู้เล่นกลางงานไม่แนะนำ (กระทบสถิติ) ถ้าจำเป็นให้แก้ที่หน้าแก้ไขผู้เล่น

M. คะแนนรวมสี

  • ชนะ 3 · เสมอ 1 ต่อทีม · แพ้ 0 รวมสะสมตลอดงาน แสดงที่ Scoreboard
  • ตรวจความถูกต้อง: ผลรวม pRed ของทุกแมตช์ที่จบ = globalScoreRed (สคริปต์ตรวจในภาคผนวก ก.5)

N. คะแนนรวมเสมอ (กติกาที่ผู้จัดตกลง)

  1. คะแนนหลักรวม (3/1 สะสม) ระบบแสดงอัตโนมัติ
  2. ผลต่างแต้มเกมย่อยรวมทุกเกม (เช่น 21–10 = +11 รวมของทั้งสี สีที่รวมมากกว่าชนะ) ระบบ ยังไม่มีหน้าสรุปตัวนี้ ใช้สคริปต์ในภาคผนวก ก.5 คำนวณ (แต้มเกมที่ถอนตัวใช้แต้มตามจริงตอนหยุด)
  3. ถ้ายังเสมอ: ตัวแทนมือ 1 + มือ 2 ลงตี 1 เกม 21 แต้ม ระบบไม่รองรับแมตช์เกมเดียวโดยตรง แนะนำแข่งนอกระบบ (กระดานคะแนนมือ) แล้วประกาศผล ถ้าใส่ผลเข้าระบบ ต้องปรับคะแนนรวมสีกลับด้วย ปรับคะแนนรวมทีม เพื่อไม่ให้แมตช์ตัดสินไปบวกคะแนนสี

O. จบงาน / ประกาศผล

  • Admin → สรุปผลการแข่งขัน (Ceremony) เปิดหน้าสรุปและส่งภาพถ้วยขึ้นจอ TV ทุกเครื่อง (กดตอนประกาศจริง)
  • รางวัล MVP / อันดับรายบุคคลคำนวณจากแมตช์ทั้งหมดที่บันทึก ระบบยังไม่ตัด “แมตช์ตัวแทน/แมตช์รอง” ออกจากอันดับ ถ้าผู้จัดตกลงว่าตัวแทนไม่นับเชิดชู ให้ตัดสินรางวัลรายบุคคลเองจากข้อมูลส่งออก (CSV)
  • ส่งออก PDF/CSV จากหน้าผู้เล่นและ Reports เก็บไว้หลังงาน

P. สำรองและกู้คืนข้อมูล

  • Backup อัตโนมัติ: หลังจบทุกแมตช์, ก่อน Reset, ก่อนกู้คืน เก็บ 30 ชุดล่าสุดที่ sportsday_2026_backups (มีรายการผู้เล่น แมตช์ และคะแนนรวมครบ)
  • กู้คืน: Super Admin → Backup & Restore → เลือกชุด (ดูเวลา เหตุผล จำนวนแมตช์ คะแนนรวม) → กู้คืน ข้อมูลปัจจุบันถูกแทนที่ทั้งหมด แต่ระบบสำรองของปัจจุบันไว้ก่อน (กู้ย้อนกลับได้)
  • Reset (ปุ่ม Reset การแข่งขัน เฉพาะ Super Admin): Reset ผลแมตช์ ล้างคิว ผลที่จบ คะแนนรวม และตั้งเลขแมตช์เป็น M01 ใหม่ (ผู้เล่นและรูปอยู่ครบ กล่องรอยังอยู่) · Reset ทั้งหมด ล้างเพิ่มโปรไฟล์ผู้เล่น ใช้ก่อนเริ่มงานจริงเท่านั้น ห้ามกดระหว่างงาน
  • เริ่ม Season ใหม่ (วิซาร์ด): ใช้ปีหน้า ไม่ใช้วันนี้

Q. เวอร์ชัน / การอัปเดต

  • ทุกเครื่องเปิดอยู่จะเห็นแถบ “มีเวอร์ชันใหม่” เมื่อมีการ deploy ใหม่ กดอัปเดตเมื่อสะดวก ห้าม deploy กลางงาน
  • ถ้าหน้าเว็บทำงานผิดปกติหลัง deploy: ล้างแคช/ปิดเปิดแท็บ ก่อนสงสัยโค้ด
  • ย้อนกลับโค้ดต้องให้เจ้าของระบบ (git) AI แนะนำได้แต่ไม่ควรสั่งทำระหว่างงาน

R. แนะนำและมอบหมายกรรมการ (รุ่น .5, เรียงตามระดับรุ่น 14.3, ชุดแรก/ชุดหลังรุ่น 14.4)

อยู่ที่ไหน: หน้า Admin เลื่อนลงใต้ “กล่องรอ & คิว” แผง กรรมการ — แนะนำ & มอบหมาย (ผู้เล่นและกรรมการทั่วไปไม่เห็นแผงนี้)

  1. ติ๊กคนที่ว่าง: ข้อ 1 ในแผงแสดงเฉพาะผู้เล่นที่มีสี แยกเป็นกล่องทีมแดงกับทีมน้ำเงิน (คนไม่มีสีไม่แสดงและไม่ถูกแนะนำ) เป็นชิป แตะเพื่อเปิด/ปิด (สีเหลือง = ว่างมาเป็นกรรมการ) มีช่องค้นชื่อ และปุ่ม ล้าง รายชื่อ ชิปบอกมือของคน (มือ 1/2/3 หรือ “ไม่ทราบระดับ” ถ้าไม่มีกลุ่มย่อย) และ “กำลังเล่น” ถ้าอยู่ในแมตช์ที่มีกรรมการแล้ว
  2. ดูคำแนะนำ: ข้อ 2 แสดงทุกแมตช์ในคิว (และกล่องรอเป็นคำแนะนำล่วงหน้า) พร้อมกรรมการแนะนำสูงสุด 3 คน (ปุ่มแรกสีเหลืองคือคำแนะนำอันดับ 1) แต่ละปุ่มบอกกลุ่มย่อย (เช่น มือ 1.2) และจำนวนแมตช์ที่คุมไปแล้ว
  3. มอบหมาย: แตะชื่อ → แมตช์นั้นขึ้นว่า “กรรมการ: ชื่อ” มีปุ่ม ยกเลิก หรือกด แนะนำทั้งหมด เพื่อมอบหมายข้อแรกให้ทุกแมตช์ในคิวที่ยังว่าง (มีหน้าต่างยืนยัน)
  4. ถัวสี: กล่องด้านบนแผงเทียบแดง/น้ำเงินว่ากรรมการสีไหนคุมไปกี่แมตช์ กี่คน (นับแมตช์ที่จบและที่กำลังคุม) ถ้าต่างกัน 3 แมตช์ขึ้นไปจะเตือน และคำแนะนำจะเอียงไปทางสีที่คุมน้อยกว่า

กติกาที่ระบบใช้แนะนำ

  • มือของกรรมการ = เลขหน้าจุดของกลุ่มย่อย (1.x = มือ 1) มือของแมตช์ = มือของคนเก่งที่สุดในแมตช์ มือ 3 คุมได้เฉพาะแมตช์มือ 3 มือ 1–2 คุมได้ทุกแมตช์ แมตช์มือ 3 ใช้กรรมการมือ 3 ก่อน ถ้าไม่มีว่างค่อยใช้มือ 1–2 คนที่ไม่มีกลุ่มย่อยถือเป็นมือ 3
  • แมตช์ชุดแรก vs แมตช์หลัง (รุ่น 14.4): 5 แมตช์แรกของคิว (5 สนามเริ่มพร้อมกัน) แนะนำกรรมการจากคนที่ ไม่ได้เล่นในชุดนั้น (เลี่ยง 2 แมตช์ถัดไปที่จะเริ่ม ถ้าเลี่ยงได้) ส่วนแมตช์ที่ 6 เป็นต้นไป (รอสนามว่าง) แนะนำเฉพาะคนที่ เล่นเสร็จแล้ว คือไม่มีแมตช์เหลือในคิว กล่องรอ หรือบนสนาม ถ้ายังไม่มีใครเล่นเสร็จและติ๊กว่าง แผงจะบอกเหตุผลแทนการแนะนำคนที่ยังไม่ได้เล่น ป้ายในแผงบอก “เริ่มก่อน” / “หลังมีคนเล่นเสร็จ” และชิปรายชื่อบอก “รอเล่น” / “เล่นเสร็จ” / “กำลังเล่น” ปุ่ม แนะนำ 5 แมตช์แรก มอบหมายข้อแรกให้ 5 แมตช์แรกของคิวเท่านั้น ให้จัดลำดับคิว (ลากคู่ที่ 10 ขึ้นมาเป็นคู่แรกได้) ให้เสร็จก่อนค่อยกด คำแนะนำคิดตามลำดับคิวปัจจุบันเสมอ แต่การมอบหมายที่กดไปแล้วผูกกับแมตช์ ไม่เปลี่ยนตามเมื่อสลับลำดับ
  • ไม่แนะนำ: ผู้เล่นในแมตช์นั้น, คนที่กำลังเล่นหรือกำลังคุมอยู่, คนที่ถูกแนะนำ/มอบหมายให้แมตช์อื่นแล้ว
  • ลำดับ: คนระดับสูงมาก่อน (1.1 → 1.2 → 2.1 → 2.2 → 2.3 → 3.1 → 3.2) แต่ถ่วงด้วยจำนวนแมตช์ที่คุมไปแล้ว คะแนน = แมตช์ที่คุม (นับที่จองไว้) + 0.5 ต่อระดับที่ต่ำกว่า 1.1 คะแนนน้อยสุดก่อน ดังนั้นต้นงานจะแนะนำคนเก่งก่อน แต่คนเก่งที่คุมไปแล้วมากกว่าคนที่อ่อนกว่า 2 แมตช์ขึ้นไปจะถอยลง เสมอกัน → สีที่คุมน้อยกว่า → รอนานสุด → ชื่อ เป็นแค่คำแนะนำ แอดมินเลือกคนอื่นได้ และกรรมการคนอื่นรับแมตช์แทนได้

สิ่งที่ต้องรู้ (สำคัญ)

  • การมอบหมายเป็นแค่ “การจอง” ไม่ใช่การล็อก กรรมการคนอื่นยังกดรับแมตช์นั้นแทนได้ทันที (เช่น เดินไปถึงสนามก่อน) ระบบไม่ขวางและไม่ถามยืนยัน
  • หน้ากรรมการแสดงป้าย “จองให้คุณ” / “จองให้ ○○” และแบนเนอร์ด้านบน “ทีมงานมอบหมายให้คุณ: Mxx” (แสดงอย่างเดียว)
  • ต้องเป็นแมตช์ที่ต่อคิวแล้วถึงจะกดมอบหมายได้ แมตช์ในกล่องรอมีแต่คำแนะนำ และเมื่อกด ต่อคิว การจองเดิม (ถ้ามี) ไม่ถูกคัดลอกไป
  • ถ้าแมตช์ถูกปล่อยกลับคิว (ปล่อยแมตช์) การจองยังอยู่ ยกเลิกได้ด้วยปุ่ม ยกเลิก ในแผง
  • ไม่มีสวิตช์ “ฉันว่าง” ฝั่งกรรมการ แอดมินเป็นคนติ๊กรายชื่อเอง รายชื่อเก็บที่ umpire_2026/avail
  • ปัญหาที่พบบ่อย: ไม่มีคำแนะนำ → ยังไม่ได้ติ๊กคนว่าง หรือคนที่ติ๊กระดับไม่พอ/กำลังเล่นอยู่ (แผงบอกเหตุผลใต้แมตช์) · ชื่อกรรมการที่จองไม่ตรงกับคนที่เปิดแอป → กรรมการต้องเลือกชื่อเดียวกับในรายชื่อผู้เล่นเป๊ะ ๆ

ภาคผนวก ก. หลังบ้าน (ใช้เมื่อไม่มีทางอื่น)

คำเตือน: ฐานข้อมูลเปิดสาธารณะ (ไม่มีรหัส) คำสั่งด้านล่างแก้ข้อมูลจริงทันที ทำเมื่อมีคนที่เข้าใจอยู่ด้วย และ สำรองก่อนเสมอ ห้ามเขียนทับโหนดราก sportsday_2026_data ทั้งก้อน ใช้เฉพาะโหนดย่อยที่ต้องการ

ก.4 ลบแมตช์ค้างในคิวอย่างปลอดภัย (แบบมีเงื่อนไขกันชนกัน)

ใช้เมื่อปุ่มในแอปลบไม่ได้ ตรวจรหัสแมตช์ก่อน แล้วลบด้วยเงื่อนไข ETag เพื่อไม่ทับข้อมูลที่เพิ่งเปลี่ยน:

# 1) อ่านพร้อม ETag
curl -s -D - -H "X-Firebase-ETag: true" "$D/sportsday_2026_data/ongoingMatches.json" -o q.json | grep -i etag
# 2) ดู q.json ให้แน่ใจว่าเป็นรายการที่จะลบจริง และไม่มี umpire/คะแนน
# 3) ลบ (ใส่ค่า ETag จากข้อ 1; ถ้าข้อมูลเปลี่ยนไประหว่างนั้น คำสั่งจะล้มเหลวเอง)
curl -s -X DELETE -H "if-match: ETAG_VALUE" "$D/sportsday_2026_data/ongoingMatches.json"
# ลบบันทึกสุ่มรอบ 2 (ถ้าลบคู่รอบ 2 ทั้งหมด)
curl -s -X DELETE "$D/draw_2026/round2.json"

การลบทั้งคิวเหมาะเมื่อต้องการล้างทั้งหมด ถ้าจะลบเฉพาะแมตช์เดียว ให้ใช้ปุ่มในแอปแทน (ข้อมูลคิวเป็นอาร์เรย์ ลบทีละรายการตรง ๆ จะทำลำดับเพี้ยน)

ก.5 สคริปต์ตรวจ/คำนวณ (อ่านอย่างเดียว) รันใน Node 18+ หรือคอนโซลเบราว์เซอร์

const D='https://badminton-2026-687e7-default-rtdb.asia-southeast1.firebasedatabase.app';
const d=await (await fetch(D+'/sportsday_2026_data.json')).json();
const H=Array.isArray(d.matchHistory)?d.matchHistory:Object.values(d.matchHistory||{});
const T={red:{pts:0,diff:0,gw:0},blue:{pts:0,diff:0,gw:0}};
const win=(r,b,ret)=>ret==='red'?'b':ret==='blue'?'r':r>b?'r':b>r?'b':'';
for(const h of H){ const [a,b]=(h.game1||'0:0').split(':').map(Number); const [c,e]=(h.game2||'0:0').split(':').map(Number);
  T.red.pts+=h.pRed||0; T.blue.pts+=h.pBlue||0;
  T.red.diff+=(a-b)+(c-e); T.blue.diff+=(b-a)+(e-c);
  [[a,b,h.ret1],[c,e,h.ret2]].forEach(([x,y,ret])=>{const w=win(x,y,ret); if(w==='r')T.red.gw++; if(w==='b')T.blue.gw++;}); }
console.log('matches',H.length,'app score',d.globalScoreRed,d.globalScoreBlue,'recomputed',T);

ผลลัพธ์: pts = คะแนนรวม (3/1) ที่คำนวณใหม่ (ต้องเท่า globalScoreRed/Blue ถ้าไม่เท่า มีการปรับคะแนนด้วยมือหรือข้อมูลเพี้ยน), diff = ผลต่างแต้มรวมทุกเกม (ใช้ตัดสินเสมอข้อ 2), gw = จำนวนเกมย่อยที่ชนะ (นับเกมที่ถอนตัวเป็นของฝั่งที่ไม่เจ็บ)

ภาคผนวก ข. ข้อจำกัดที่ยังไม่มีในระบบ (อย่าเสียเวลาหาปุ่ม)

  • เปลี่ยนผู้เล่นในแมตช์ที่สร้างแล้ว หรือกลางแมตช์ (ใช้ลบ+สร้างใหม่ หรือแก้ผลทีหลัง)
  • แมตช์ตัวแทน/แมตช์รอง ที่ไม่นับอันดับ/MVP (ผู้จัดตกลงหลักการไว้แล้ว ยังไม่ได้ทำในโค้ด)
  • หน้าสรุปตัดสินเสมออัตโนมัติ (ผลต่างแต้มรวม) และแมตช์ตัดสิน 1 เกม 21 แต้ม
  • สวิตช์ “ฉันว่าง” ฝั่งกรรมการ และการล็อกแมตช์ที่จองไว้ (ตอนนี้จองได้แต่ใครก็รับแทนได้ — ตั้งใจ)
  • ฟอร์มคีย์คู่เร็วสำหรับรอบ 1/3 (ตอนนี้คีย์ทีละแมตช์ที่กระดานสร้างแมตช์)
  • ล็อกสิทธิ์ฐานข้อมูลฝั่งเซิร์ฟเวอร์ (ตอนนี้เปิดโดยตั้งใจ กันไม่ได้ว่ามีคนยิงข้อมูลตรง)

ภาคผนวก ค. สิ่งที่ AI ควรถามกลับก่อนช่วยแก้

  1. เกิดกับ แมตช์รหัสอะไร คอร์ตไหน กรรมการชื่ออะไร
  2. บนหน้าจอเห็น ข้อความ/ปุ่มอะไรเป๊ะ ๆ (ขอให้พิมพ์หรือถ่ายภาพ)
  3. ผู้ใช้เป็นบทบาทอะไร (Admin หรือ Super Admin) เพราะบางปุ่มเห็นเฉพาะ Super Admin
  4. ผู้จัดทั้งสองสีตกลงวิธีแก้แล้วหรือยัง (กรณีตัดสินผล/ตัวแทน)
  5. สำรองข้อมูลล่าสุดเมื่อกี่โมง
