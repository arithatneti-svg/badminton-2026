# แผน: จัดกรรมการ (Umpire assign) + วางแมตช์รอบ 1 / 3

สถานะ: **แผนเท่านั้น ยังไม่ได้เขียนโค้ด** · ร่าง 2026-11-13

## เป้าหมาย
1. กรรมการบอกเองว่า "ว่าง" หรือไม่ว่าง
2. แอดมินมีแท็บใหม่ "กรรมการ" ที่แนะนำว่าแมตช์ไหนควรให้ใครคุม แล้วกดมอบหมายได้ทีเดียว
3. กรรมการที่ถูกมอบหมาย แค่เปิดหน้ากรรมการ เลือกชื่อ แล้วกด "ยืนยันรับแมตช์" ก็จบ
4. ถ้าแอดมินไม่ได้มอบหมาย กรรมการยังกดเลือกแมตช์เองได้เหมือนเดิม

## ข้อมูลที่ใช้ (ของที่มีอยู่แล้ว)
- ผู้เล่นทุกคนมี `group` (G1..) และ `sub` (1.1 … 3.2) — "มือ" ในแผนนี้ = เลขหน้าจุดของ `sub` (1.x = มือ 1, 2.x = มือ 2, 3.x = มือ 3) **ต้องยืนยัน**
- กรรมการ = ผู้เล่นที่เลือกชื่อตัวเองในหน้า `/umpire` (ไม่มีรหัสผ่าน เก็บชื่อใน localStorage)
- แมตช์ที่มีกรรมการ = ฟิลด์ `umpire` ในแมตช์ (ระบบรับแมตช์แบบกันชนกันมีอยู่แล้ว)

## ข้อมูลใหม่ (โหนดแยก ไม่แตะก้อนคะแนนหลัก)
- `umpire_2026/avail/{playerId}` = `{ on: true, at: เวลา }` — กรรมการกดสวิตช์ "ว่างตัดสิน" เอง
- ในแต่ละแมตช์ (ทั้งกล่องรอและคิวจริง) เพิ่มฟิลด์ `assigned: "ชื่อกรรมการ"` = จองไว้ให้คนนี้
- ประวัติ "เคยตัดสินกี่แมตช์ / จบล่าสุดเมื่อไร" **คำนวณจากแมตช์ที่จบแล้ว** ไม่ต้องเก็บเพิ่ม

## การทำงาน
**หน้ากรรมการ (`/umpire`)** — เพิ่มสวิตช์ "ฉันว่างตัดสิน" และแถบด้านบน "ทีมงานมอบหมาย M07 ให้คุณ [ยืนยันรับ]" แมตช์ที่ถูกจองไว้ให้คนอื่นจะแสดงว่า "จองให้ ○○" และกดรับไม่ได้ (แอดมินปล่อยได้) แมตช์ที่ไม่ได้จองเลือกเองได้เหมือนเดิม

**แท็บแอดมิน "กรรมการ"**
- รายชื่อกรรมการที่ว่าง: สถานะ (ว่าง / กำลังตัดสิน M07 / พัก), จำนวนแมตช์ที่เคยตัดสิน, ว่างมานานกี่นาที
- ต่อแมตช์รอ แสดง "แนะนำ: เพชร, โจ๊ก, ก๊อป" (3 คน) กดชื่อเดียวเพื่อมอบหมาย
- ปุ่ม "แนะนำทั้งหมด" เติมให้ทุกแมตช์รอในครั้งเดียว แล้วแอดมินแก้รายตัวได้
- มอบหมายแล้วยกเลิก/เปลี่ยนคนได้

## เกณฑ์แนะนำ (เรียงตามความสำคัญ)
1. **ต้องว่าง** (กดสวิตช์) และ **ไม่ได้ลงเล่นในแมตช์นั้น** และ **ไม่ได้กำลังเล่น/คุมแมตช์อื่นอยู่**
2. **ระดับมือต้องพอ** (ตารางด้านล่าง)
3. **เฉลี่ยงาน**: คนที่เคยตัดสินน้อยกว่าก่อน แล้วค่อยดูว่าพักนานกว่า
4. **ถัวสีกรรมการ** (เกณฑ์อ่อน): ถ้าผู้สมัครเท่ากันหมด ให้เลือกสีที่ยังคุมน้อยกว่า (ทั้งจำนวนคนและจำนวนครั้ง)

### ถัวสีกรรมการ (กราฟในแท็บแอดมิน "กรรมการ")
- แถบเทียบแดง vs น้ำเงิน 2 ชุด: **จำนวนกรรมการที่ไม่ซ้ำคน** และ **จำนวนแมตช์ที่คุมไปแล้ว** (รวมที่กำลังคุมอยู่)
- ถ้าต่างกันเกินเกณฑ์ (เสนอ ≥ 3 แมตช์) ขึ้นป้ายเตือน "สีน้ำเงินคุมน้อยกว่า" และการแนะนำจะเอียงไปทางสีนั้นโดยอัตโนมัติ
- คำนวณจากแมตช์ที่จบแล้ว + ที่กำลังแข่ง ไม่ต้องเก็บข้อมูลเพิ่ม

### ตารางระดับมือที่เสนอ (ขอให้ยืนยัน)
"มือแมตช์" = มือของผู้เล่นที่เก่งที่สุดในแมตช์นั้น

| มือแมตช์ \ มือกรรมการ | มือ 1 | มือ 2 | มือ 3 |
|---|---|---|---|
| มือ 1 | ✅ | ✅ (ขั้นต่ำ) | ❌ |
| มือ 2 | ✅ | ✅ | ❌ |
| มือ 3 | ✅ | ✅ | ✅ |

อ่านแบบนี้: มือ 3 คุมได้เฉพาะแมตช์มือ 3 เท่านั้น ส่วนมือ 1–2 คุมได้ทุกแมตช์ ถ้าที่ตั้งใจไม่ใช่แบบนี้ (เช่น มือ 1 ไม่ควรไปคุมแมตช์มือ 3) แก้ตารางนี้ได้เลย

## ตัดสินใจแล้ว (2026-11-13, เจ้าของระบบตอบ)
1. **"มือ" = เลขหน้าจุดของ `sub`** (1.x = มือ 1 = กลุ่ม 1, 2.x = กลุ่ม 2, 3.x = กลุ่ม 3)
2. ตารางด้านบนถูกต้อง: **มือ 3 คุมได้เฉพาะแมตช์มือ 3**, มือ 1–2 คุมได้ทุกแมตช์
   - ตอนแนะนำ **จับมือ 3 กับแมตช์มือ 3 ก่อนเป็นหลัก** เก็บมือ 1–2 ไว้คุมแมตช์ระดับตัวเอง ใช้มือ 1–2 คุมแมตช์มือ 3 เฉพาะเมื่อไม่มีมือ 3 ว่าง
3. กรรมการที่ถูกมอบหมายได้ **สิทธิ์หลัก แต่ใครจะ "เทคโอเวอร์" ก็ได้เลย** ไม่มีตัวนับเวลา (เช่น เรียกแล้วคนอื่นเดินไปถึงสนามก่อน)
   - ผลต่อการออกแบบ: `assigned` เป็นแค่ "ป้ายจอง/คำแนะนำ" ไม่ใช่ตัวล็อก คนอื่นกดรับได้ แต่ขึ้น "จองให้ ○○ — รับแทนไหม?" ให้ยืนยันอีกครั้ง ใช้ transaction รับแมตช์เดิมที่กันชนกันอยู่แล้ว (ตัดข้อ "หลุดอัตโนมัติ" ออกจากระยะ C)
4. **กติกาจับคู่ต่างกันทั้ง 3 รอบ**: รอบ 2 ใช้ระบบสุ่ม (ทำแล้ว) ส่วน **รอบ 1 และรอบ 3 เจ้าของระบบคีย์คู่เข้าเอง** (ตกลงนอกระบบว่าใครคู่ใคร) ให้ไปอยู่ที่ "แมตช์รอ" แล้วค่อยเลือกส่งเข้าคิว
   - ผลต่อการออกแบบ: ระยะ D ไม่ต้องมีตัวสุ่มและไม่ต้องรู้กติกา แค่ **ฟอร์มคีย์คู่แบบเร็ว** (เลือกผู้เล่น 4 คนต่อแมตช์ หลายแมตช์ในหน้าเดียว) เขียนลงกล่องรอเหมือนที่หน้ารอบ 2 ทำ

5. **สีของกรรมการ:** กรรมการเป็นผู้เล่นสีแดงหรือน้ำเงินอยู่แล้ว และทุกแมตช์คือแดงเจอน้ำเงิน จึงหลีกเลี่ยงสีไม่ได้ → ไม่ใช้เกณฑ์ "ห้ามสีเดียวกับผู้เล่น" แต่ **ต้องถัวสีให้เท่ากัน** และมี **กราฟโชว์** ว่ากรรมการสีแดง/น้ำเงินคุมไปกี่คน กี่ครั้ง (ดูหัวข้อ "ถัวสีกรรมการ")

## ตัวแทน (ซับ) และแมตช์รอง — สถิติ
**สถานการณ์:** ผู้เล่นบางคนมาไม่ได้ (เช่น พี่ต้นรอบ 3) ต้องหาคนมาแทน ทำให้บางคนเล่น **เกิน 2 เกมต่อรอบ**

**หลักการของเจ้าของระบบ**
- คนที่เล่นเยอะเพราะเป็นตัวแทน **ต้องไม่ได้เปรียบ** ในการ "เชิดชู" (เล่นมาก = มีโอกาสทำแต้มมาก)
- แมตช์รอง **นับคะแนนให้สี** เสมอ (ผลจริงของแมตช์)
- แมตช์รอง **นับในตัวเลขส่วนตัวได้** (ดูในโปรไฟล์ได้ครบ) แต่ **ไม่นับในสิ่งที่เชิดชู**: อันดับ, โพเดียม, MVP/ท็อป, รางวัล

**ตัดสินใจแล้ว**
1. คะแนนทีมนับแมตช์รอง ✅
2. คู่หูของตัวแทน ยังนับตามปกติ ✅ (ป้ายตัวแทนติดที่ "ตัวแทนคนนั้น" ไม่ใช่ทั้งแมตช์)
3. สถิติเก่า ทุกแมตช์ถือเป็นแมตช์หลักตามเดิม ✅
4. ข้อ "ตัวแทนที่ไม่มีแมตช์หลักเลย" และ "ตั้ง extra อัตโนมัติหรือแอดมินกด" ผู้ใช้ไม่เข้าใจ → ใช้ค่าเริ่มต้นง่าย ๆ ด้านล่าง ไม่ต้องตัดสินใจ

**วิธีทำ (ค่าเริ่มต้นที่ผมเลือกให้)**
- ผู้เล่นแต่ละคนในแมตช์มีป้าย "ตัวแทน" ได้: ฟิลด์ `extra: [playerId, …]` ในแมตช์ (กล่องรอ คิว และประวัติที่จบแล้ว) ค่าเริ่มต้น = ไม่มีป้าย = แมตช์หลัก
- **แอดมินกดเองเท่านั้น** ในการ์ดกล่องรอ: ปุ่มเล็กข้างชื่อผู้เล่นแต่ละคน "ตัวแทน" กดสลับ ใครมีป้าย ถือว่าแมตช์นั้นเป็นแมตช์รองของคนนั้น (แม้เขาจะเล่นแมตช์เดียวก็ตาม) ระบบไม่ตั้งเอง
- เตือนเฉย ๆ เมื่อมีคนถูกใส่ในแมตช์ที่ 3 ขึ้นไปของรอบเดียวกัน เพื่อให้แอดมินนึกถึงการติดป้าย ไม่บังคับ
- **ตัวเลขส่วนตัว** (แต้ม ชนะ/แพ้ อัตราชนะ) ใน `getPlayerStats` นับครบทุกแมตช์เหมือนเดิม + เพิ่มตัวนับแยก `extraPlayed / extraWon` และแต้มเฉพาะแมตช์หลัก `rankPts / rankW`
- **ทุกที่ที่จัดอันดับ/เชิดชู** เปลี่ยนไปใช้ค่าเฉพาะแมตช์หลัก: รายชื่อผู้เล่นเรียงตามแต้ม + โพเดียม (js/season.js), กราฟ 20 อันดับ (js/dashboard.js), MVP และใบเกียรติบัตร (js/effects.js), PDF (js/pdf-export.js), อันดับในโปรไฟล์ (js/player-profile.js), ประวัติหลายปี (js/career.js)
- โปรไฟล์โชว์บรรทัดเล็ก "แมตช์รอง: เล่น N ชนะ M (ไม่นับอันดับ)"
- ผลแมตช์บันทึกครบ ไม่ลบ ไม่แก้ย้อนหลัง
- ต้องมีเทสต์ใหม่ (stats ตัวอย่างที่มี extra) ก่อนขึ้นระบบ

**ตัวอย่างสำหรับข้อที่ไม่เข้าใจ:** รอบ 3 พี่ต้นมาไม่ได้ น้องเอ (ไม่มีแมตช์ในรอบนั้นเลย) มาเล่นแทนแมตช์เดียว → แอดมินกด "ตัวแทน" ข้างชื่อน้องเอ → ผลนั้นนับให้สีของน้องเอ และขึ้นในตัวเลขของน้องเอ แต่ไม่ทำให้น้องเอขึ้นอันดับ/โพเดียม ถ้าคุณอยากให้เกมเดียวนั้นนับอันดับด้วย ก็แค่ไม่กดป้าย

- (ข) **ผลต่างเกมย่อย** = **ผลต่างแต้มรวมทุกเกม** (ไม่ใช่จำนวนเกมที่ชนะ) เช่น 21-10 = +11 แล้วรวมทั้งสี ใครมากกว่าชนะ เพราะทุกแมตช์เป็นแดงเจอน้ำเงินเกมเท่ากันอยู่แล้ว → ต้องเพิ่มผลรวมแต้มได้-เสียต่อสีในหน้าสรุป (ระบบมีผลต่างแต้มต่อคนแล้ว ไม่มีต่อสี)
- (ค) เกมที่แพ้เพราะเจ็บ **หยุดที่แต้ม ณ ตอนนั้น** แล้วใช้ตัวเลขนั้นในผลต่างแต้ม **(ประโยค "หยุดไปที่ 21 กับแต้มเท่านั้น" ยังกำกวม: ต้องถามว่าฝ่ายที่ชนะเกมถูกปัดเป็น 21 หรือใช้แต้มจริง)**

## แผนงาน (เสนอ)
| ระยะ | งาน | ความเสี่ยง |
|---|---|---|
| A | สวิตช์ "ว่าง" + แท็บแอดมินดูรายชื่อ/สถิติ (ยังไม่มอบหมาย) | ต่ำ |
| B | ช่องแนะนำต่อแมตช์ + มอบหมาย + แถบ "ยืนยันรับ" ที่หน้ากรรมการ | กลาง (แตะขั้นตอนรับแมตช์) |
| C | "แนะนำทั้งหมด" (ไม่มีหลุดอัตโนมัติ ใครก็เทคโอเวอร์ได้) | กลาง |
| D | ฟอร์มคีย์คู่เร็วสำหรับรอบ 1 / รอบ 3 เข้ากล่องรอ | ต่ำ (ไม่มีตัวสุ่ม) |
| E | ป้ายตัวแทน/แมตช์รอง (extra) + ทุกอันดับ/เชิดชูใช้เฉพาะแมตช์หลัก | กลาง (แตะตัวคำนวณสถิติ + 6 ที่แสดงอันดับ ต้องมีเทสต์) |
| F | กราฟถัวสีกรรมการ (แดง vs น้ำเงิน) ในแท็บ "กรรมการ" | ต่ำ |

**ข้อเสนอเรื่องเวลา:** ระยะ B ไปแตะขั้นตอนที่กรรมการ 5 คอร์ตใช้จริงบนสนาม ไม่ควรขึ้นระบบคืนก่อนวันงาน เสนอให้ทำเสร็จและทดสอบกับมือถือกรรมการจริงหลังวันเสาร์ ส่วนวันเสาร์ใช้การรับแมตช์เองแบบเดิม
