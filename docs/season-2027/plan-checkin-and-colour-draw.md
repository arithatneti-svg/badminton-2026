# แผน Sports Day 2027: ล้างสี → เช็กอิน → สุ่มสี → หน้าเปิดตัวทีม

เขียนจากที่เจ้าของระบบเล่าไว้ (2026-10-30) และจากการอ่านโค้ดปัจจุบัน ยังไม่ได้ลงมือแก้โค้ดส่วนนี้

## สิ่งที่ระบบมีอยู่แล้ว (ใช้ต่อได้)
- ผู้เล่นมี `pid` (เลขประจำตัวถาวรข้ามซีซั่น เช่น P001) = "ยูเซอร์เลขไหน" ที่เจ้าของพูดถึง และมี `id` (เบอร์เสื้อ R07/B21 ที่ตัวอักษรหน้าตามสี) กับ `team` ('Red'/'Blue') และ `group` (G1-G3)
- วิซาร์ดเริ่ม Season ใหม่ (`js/season.js`): เก็บ Archive → เลือกคนที่เล่นต่อ + เปลี่ยนสี/สุ่มสี → เพิ่มผู้เล่นใหม่ → ยืนยัน (ออกเบอร์เสื้อใหม่ตามสี ยกโปรไฟล์ไปคีย์ใหม่ ล้างผลแข่ง)
- ตัวเลือก "ฉันคือใคร" (`js/me.js`): เลือกชื่อครั้งเดียว เก็บในเครื่อง (localStorage) ไม่เขียนลงฐานข้อมูลกลาง
- โปรไฟล์เก็บ มือถนัด / ลูกถนัด / สไตล์การเล่น (`prof.hand`, `prof.dominantShot`, `prof.styles`)
- ประวัติข้ามปี: `masterPlayers` (ตาม pid) และ `seasons_archive/<ปี>` ใช้ดึง "ปีที่แล้วชนะ/แพ้ ทีมอะไร คะแนนเท่าไร"
- หน้าทีวีและระบบแผงหมุนเวียน (`js/tv.js`) ใช้ทำหน้าเปิดตัวทีมได้

## สิ่งที่ต้องระวัง (พบตอนอ่านโค้ด)
- มี ~40 จุดที่เช็ก `team === 'Red'` แล้วถือว่า "ที่เหลือคือ Blue" (รายชื่อ, ตัวเลือกจับคู่, รายงาน, ทีวี, แอปกรรมการ, PDF) ผู้เล่นที่ยังไม่มีสีจะถูกวาดเป็น Blue ถ้าไม่แก้ทุกจุดให้มีสถานะที่สาม "ยังไม่มีสี"
- รูปผู้เล่นและโปรไฟล์คีย์ด้วย `id` (เบอร์เสื้อ) ถ้าเบอร์เสื้อเปลี่ยนตามสีหลังสุ่ม รูปกับโปรไฟล์ต้องย้ายคีย์ตาม
- การให้ผู้เล่นกดสุ่มสีเองคือ "ผู้ชมเขียนข้อมูลกลาง" ต้องมีกฎ Firebase (เขียนได้ครั้งเดียวต่อคน) ไฟล์กฎไม่อยู่ใน repo (อยู่ใน Firebase console) ต้องให้เจ้าของอนุมัติก่อน

## เฟส
### เฟส 1: เริ่มซีซั่นแบบ "ยังไม่มีสี" (แอดมิน)
- วิซาร์ดขั้น 3: ค่าเริ่มต้นของคอลัมน์สี = "ยังไม่มีสี (รอสุ่ม)" มีปุ่ม "ล้างสีทั้งหมด" และยังเลือกสีเองได้ ผู้เล่นใหม่เพิ่มด้วยชื่อ + กลุ่ม (ไม่ต้องใส่สี)
- ผู้เล่นที่ไม่มีสี: เลขประจำตัว = pid, ไม่มีตัวอักษร R/B, ถูกวาดเป็นชิปเส้นประ "ยังไม่มีสี" (ไม่ใช่ Blue), ไม่ปรากฏในตัวเลือกจับคู่จนกว่าจะมีสี
- ตรวจและแก้ทุกจุดที่ถือว่า "ไม่ใช่ Red = Blue" ผ่านตัวช่วยกลางตัวเดียว
- รูปและโปรไฟล์: คีย์ด้วย pid ตั้งแต่ซีซั่นนี้ (ไม่ย้ายคีย์ตามสีอีก)
### เฟส 2: เช็กอิน + คำทักทาย
- ต่อจาก "ฉันคือใคร": เลือกชื่อ แล้วขึ้นการ์ดต้อนรับ
  - ผู้เล่นเก่า: ทักตามผลปีที่แล้ว เช่น แพ้ → "ปีที่แล้วแพ้ ปีนี้พร้อมล้างแค้นหรือยัง?" ชนะ → "แชมป์ปีที่แล้ว ปีนี้จะรักษาไว้ได้ไหม?" กลางๆ → "กลับมาอีกครั้ง!" พร้อมสถิติปีที่แล้ว (ทีม ผล คะแนน อันดับ รางวัล)
  - ผู้เล่นใหม่: "ยินดีต้อนรับสู่ Sports Day 2027"
  - การ์ดสไตล์: มือถนัด ลูกถนัด สไตล์การเล่น ตามที่เก็บไว้ ถ้ายังว่างให้กรอกเองสามแตะ
### เฟส 3: สุ่มสี
- 3a (ทำได้ทันที ไม่ต้องแก้กฎ): แอดมินกด "สุ่มสี" บนจอใหญ่ ไล่เปิดทีละคนพร้อมแอนิเมชัน
- 3b (หลังเจ้าของอนุมัติกฎ Firebase): ผู้เล่นกดสุ่มเองบนมือถือ ได้ครั้งเดียว ล็อกหลังสุ่ม แอดมินย้อนได้
- ตรรกะสุ่ม (ยังพักไว้ตามเจ้าของ): ค่าตั้งต้นที่แนะนำ = จำนวนสองทีมเท่ากัน แล้วถ่วงรายกลุ่ม G1/G2/G3 ให้สมดุล เปลี่ยนตรรกะภายหลังได้โดยไม่แตะหน้าจอ
### เฟส 4: หน้าเปิดตัวทีมก่อนเริ่มรายการ
- แผงทีวีและหน้าบนคอม "ใครอยู่สีไหน": สองคอลัมน์ RED / BLUE ขึ้นสดตามที่สุ่ม ช่อง "?" ของคนที่ยังไม่สุ่ม นับ x/y คนแล้ว
- ผู้เล่นที่ไม่มีรูปใช้ภาพแทน (ดาวมาสคอต) แอดมินใส่รูปทีหลังได้เหมือนเดิม
### เฟส 5: รูป
- เจ้าของใส่รูปผู้เล่นเก่าเอง ทีมงานใส่รูปผู้เล่นใหม่ผ่านหลังบ้านที่มีอยู่แล้ว

## ค่าที่ผมตัดสินใจไว้ให้ (เปลี่ยนได้)
1. ตัวระบุ: ใช้ pid ตลอด เลิกใส่ตัวอักษร R/B ในเบอร์ ให้สีบอกทีมแทน
2. สุ่มครั้งแรกทำแบบแอดมินกดบนจอใหญ่ (3a) ก่อน ผู้เล่นกดเอง (3b) ตามหลังเมื่อกฎ Firebase พร้อม
3. "ล็อกอิน" = เลือกชื่อ (ไม่มีรหัส) เพราะเป็นงานเพื่อนๆ ถ้าต้องกันการแอบกดแทนกัน ค่อยเพิ่มรหัส 4 หลัก

## ลำดับที่แนะนำ
เฟส 1 → เฟส 4 + 3a (ได้ฉากเปิดตัวใช้งานจริง) → เฟส 2 → เฟส 3b → เฟส 5
